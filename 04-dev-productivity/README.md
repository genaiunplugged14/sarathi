# 04-dev-productivity

Exam scenario: Developer Productivity with Claude.

Lesson 19 explores `store/`, a small online store back end you have never
seen, with Claude Code's built-in tools: Grep for what is inside files, Glob
for file names, Read to follow one file to the next. Fake data only.

```bash
uv run python -m unittest discover -s 04-dev-productivity -t 04-dev-productivity
```

The MCP server for the support tools is built in lesson 20, in
`01-support-agent/mcp_server.py`, and started from `.mcp.json` in the repo root.
