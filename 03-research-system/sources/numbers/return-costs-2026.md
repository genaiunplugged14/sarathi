# What a return costs us

Date: 2026-09-30. Fake data for the Sarathi course.

- Handling one return costs 11 dollars on average (shipping label,
  inspection, restocking).
- An opened monitor or pair of headphones resells at 82 percent of
  its price, so each one loses 18 percent.
- The finance team estimates a 60 day window would add about
  40 returns a month.
